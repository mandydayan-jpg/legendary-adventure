לוח המטלות של המשפחה - שרת עצמאי (Node.js)
==============================================

מה יש כאן
-----------
שרת Node.js קטן (Express) שמגיש גם את האפליקציה וגם שומר את כל הנתונים
(משתמשים, קבוצות, מטלות, התראות) בקובץ db.json. אין תלות בגוגל,
Firebase, או כל שירות חיצוני - הכל רץ במקום אחד.

הרצה על המחשב שלכם (לבדיקה)
-------------------------------
1. ודאו שמותקן Node.js (גרסה 18 ומעלה) - https://nodejs.org
2. פתחו טרמינל/שורת פקודה בתוך התיקייה הזו והריצו:
     npm install
     npm start
3. פתחו בדפדפן: http://localhost:3000

העלאה לאינטרנט (חינם, כדי שהמשפחה תוכל להתחבר מכל מקום)
-------------------------------------------------------------
מומלץ Render.com - יש להם שכבה חינמית להרצת שרתי Node.js:

1. גשו ל-https://render.com והרשמו (אפשר עם חשבון גוגל).
2. תעלו את התיקייה הזו ל-GitHub (יוצרים repository חדש וגוררים
   את הקבצים אליו דרך האתר של גיטהאב - "uploading an existing file").
3. ב-Render: "New" -> "Web Service" -> מחברים את ה-repository מגיטהאב.
4. הגדרות:
     Build Command:  npm install
     Start Command:  npm start
   ובחרו בתוכנית "Free".
5. אחרי כמה דקות תקבלו כתובת אמיתית כמו https://home-tasks.onrender.com

חשוב לדעת: בתוכנית החינמית, השרת "נרדם" אחרי כ-15 דקות בלי שימוש,
ולוקח כ-30 שניות להתעורר בפעם הבאה שמישהו נכנס. זה תקין ולא באג.

התקנה על הטלפון
------------------
אנדרואיד (כרום): נכנסים לכתובת, שלוש הנקודות -> "התקן אפליקציה".
אייפון (ספארי): נכנסים לכתובת, כפתור השיתוף -> "הוסף למסך הבית".

הערות
-------
- הסיסמאות מוצפנות (bcrypt) בקובץ הנתונים - לא נשמרות כטקסט גלוי.
- כל הנתונים נשמרים בקובץ db.json על השרת. בתוכניות חינמיות מסוימות
  (כולל Render Free) הדיסק לא קבוע לצמיתות ועלול להתאפס בפריסות עתידיות -
  אם זה קריטי לכם, אפשר בהמשך לחבר את השרת למסד נתונים אמיתי.
- התראות מתעדכנות כל 5 שניות כשהאפליקציה פתוחה (בדפדפן או כמותקנת).
  התראות שמגיעות גם כשהאפליקציה סגורה לגמרי דורשות הרחבה נוספת (Push).
