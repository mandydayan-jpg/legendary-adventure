# Pre-Breakout Squeeze Scanner

מערכת לזיהוי מניות בדחיסת מחיר (Squeeze) לפני התפרצות, על בסיס נתוני שוק אמיתיים, חדשות עם משקולות זמן, וניתוח של Claude עם אימות קשיח בצד השרת.

## ארכיטקטורה

```
frontend/app.py  (Streamlit)  ──HTTP──►  backend/main.py (FastAPI)
                                             │
              ┌──────────────────────────────┼──────────────────────────────┐
              ▼                              ▼                              ▼
     backend/scanner.py             backend/news_engine.py          backend/ai_analyzer.py
  yfinance OHLCV → 3 חוקים       yfinance / Finnhub / Polygon       Claude (structured output)
  טכניים מחושבים בקוד              30 יום, דליים + משקולות זמן               │
                                                                           ▼
                                                                  backend/validator.py
                                                    אימות מחירים, ציטוטים, תאריכים ועקביות
```

| קובץ | תפקיד |
|---|---|
| `backend/config.py` | כל הספים של ספר החוקים וההגדרות (משתני סביבה / `.env`) |
| `backend/market_data.py` | ספקי מחירים (Twelve Data → Alpha Vantage → yfinance) עם שרשרת גיבוי |
| `backend/scanner.py` | חישוב 3 התנאים הטכניים ורמות כניסה/סטופ ייחוס |
| `backend/news_engine.py` | איסוף חדשות 30 יום, הסרת כפילויות, חלוקה לדליים ומתן משקל |
| `backend/ai_analyzer.py` | בניית הפרומפט, קריאה ל-Claude עם JSON schema, טיפול בשגיאות |
| `backend/validator.py` | שכבת "אפס הזיות": בדיקת הפלט מול נתוני האמת |
| `backend/models.py` | סכמות Pydantic קשיחות (פורמט ה-JSON) |
| `backend/main.py` | שרת FastAPI |
| `frontend/app.py` | ממשק משתמש |
| `tests/test_pipeline.py` | בדיקות אופליין (ללא רשת וללא API) |

## ספר החוקים (מוטמע בקוד וב-system prompt)

1. **דחיסת מחיר** – טווח 5 הימים האחרונים < 35% מטווח 30 הימים.
2. **ייבוש מחזורים** – ממוצע נפח 3 הימים האחרונים < ממוצע 30 יום (נר יומי שעדיין לא נסגר לא נספר).
3. **קרבה להתנגדות** – המחיר עד 4% מתחת לשיא 30 הימים.
4. **קטליזטור חדשותי** – חדשות מ-30 הימים האחרונים. לדלי 0‑72 שעות שמור 70% מהמשקל, לדלי 3‑5 ימים 20%, ל-5‑30 ימים 10%. אם דלי ריק, המשקל שלו **לא** עובר לדלי אחר, כך שחוסר בחדשות טריות מוריד את הציון.

שלושת התנאים הטכניים מחושבים **בקוד**, ורק מניות שעוברות אותם (ברירת מחדל: 3/3) נשלחות ל-Claude, כדי לחסוך בעלויות.

## איך נאכף "אפס הזיות"

- **בפרומפט:** אסור ל-Claude להשתמש בידע קודם. כל מספר חייב להגיע מבלוק `<technical_data>`, וכל טענה חדשותית חייבת ציטוט מילה במילה, מזהה כתבה (`N1`, `N2`…) ותאריך. תוכן החדשות מסומן כנתון לא אמין, כדי שהוראות שמוטמנות בכתבה לא יופעלו.
- **ברמת ה-API:** הפלט מוגבל ל-JSON schema באמצעות structured outputs, ואחר כך נבדק שוב ב-Pydantic (`extra="forbid"`, טווחים 0‑100, ערכי enum).
- **בצד השרת (`validator.py`):**
  - סטופ-לוס נמוך ממחיר הכניסה וגם מהמחיר הנוכחי, ולא יותר מ-15% מתחת לכניסה.
  - מחיר הטריגר נמצא באזור הפריצה: מ-1% מתחת לשיא 30 יום ועד 5% מעליו, ומעל המחיר הנוכחי.
  - ערכי `met` הטכניים מוחלפים בערכים שהקוד חישב, וכל החלפה מוצגת למשתמש.
  - כל ציטוט מאומת: המזהה קיים, הציטוט מופיע מילה במילה בכותרת או בתקציר, והתאריך זהה לתאריך הכתבה.
  - אסור לתת ציון "חדשות אחרונות" או `BULLISH_RECENT` כשאין כתבות מ-72 השעות האחרונות.
  - `BUY_WATCHLIST` מותר רק כשכל החוקים מתקיימים וציון הביטחון 60 ומעלה; אחרת ההמלצה יורדת ל-`WAIT`.
  - כל שגיאה קשיחה מורידה את ההמלצה ל-`REJECT` ומציבה `data_verified=false`, ופירוט השגיאות מוצג בממשק.
- **נתונים:** כשאין נתונים, או שהם ישנים מ-5 ימים, המניה מדווחת כשגיאה ואינה מנותחת. המערכת לא ממציאה נתונים.

> תוספת לפורמט שביקשת: ל-`catalyst_news` נוסף מערך `citations` (`article_id`, `quote`, `date`). דרכו השרת מאמת את הראיה באופן מכני. שאר המבנה זהה לפורמט שהגדרת.

## התקנה והרצה מקומית

```bash
cd squeeze-scanner
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env               # ואז למלא ANTHROPIC_API_KEY (ואופציונלית FINNHUB_API_KEY / POLYGON_API_KEY)

# טרמינל 1 – שרת
uvicorn backend.main:app --reload --port 8000

# טרמינל 2 – ממשק
streamlit run frontend/app.py      # נפתח בכתובת http://localhost:8501
```

בדיקות (ללא רשת וללא מפתח API):

```bash
python -m pytest -q
```

## הערות

- **מקורות מחירים:** הסדר נקבע ב-`PRICE_PROVIDERS` (ברירת מחדל: `twelvedata,alphavantage,yfinance`). ספק בלי מפתח מדולג. אם ספק נכשל (למשל בגלל מגבלת קצב), עוברים לבא בתור. אם כולם נכשלים, המניה מדווחת כשגיאה עם פירוט מכל ספק. בכל שורה מוצג `data_source`, כלומר מאיזה ספק הגיעו הנתונים.
- **מקורות חדשות:** yfinance (תמיד פעיל), Alpha Vantage `NEWS_SENTIMENT`, Finnhub ו-Polygon. כל ספק מופעל רק אם הוגדר לו מפתח. yfinance מחזיר בדרך כלל רק את הכתבות האחרונות, ולכן לכיסוי מלא של 30 יום מומלץ להוסיף מפתח ל-Alpha Vantage או ל-Finnhub.
- **מגבלות שכבה חינמית:** ב-Alpha Vantage כ-25 קריאות ליום, וב-Twelve Data כ-8 קריאות לדקה ו-800 ליום. כדאי לצמצם את `SCAN_UNIVERSE` או להוריד את `MAX_WORKERS` בהתאם.
- **מודל:** ברירת המחדל היא `claude-opus-5-5` עם `effort=high`. מופעל fallback בצד השרת (`fallbacks: "default"`) למקרה שמסווג בטיחות דוחה בקשה. אפשר לכבות אותו עם `ANTHROPIC_FALLBACKS=0`.
- **"זמן אמת":** הנר היומי האחרון כולל את המחיר העדכני במהלך המסחר, אבל הוא לא נכלל בחישוב הנפח עד הסגירה. הנתונים של yfinance עשויים להגיע בעיכוב של כ-15 דקות.
- המערכת היא כלי סינון ומחקר, לא ייעוץ השקעות.
